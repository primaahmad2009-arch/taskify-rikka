# Taskify Vue — Rikka background + puzzle verification

Run in VS Code terminal:

```bash
npm install
npm run dev
```

Open the localhost URL shown by Vite. The provided image is bundled locally in `src/assets/rikka-yuta.jpg`. Tasks are stored in localStorage. Delete confirmation uses a changing visual-selection puzzle (client-side demo, not a security CAPTCHA).


Statistik: total tugas, belum selesai, selesai, dan persentase progress dihitung otomatis dari daftar tugas.
